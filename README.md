# شتريد؟ موجود! — تطبيق الزبون 🛍️

مشروع Flutter أندرويد لخدمات ومتاجر كل بغداد.

## جدول متابعة التطوير
- [افتح ملف جدول المهام التفاعلي](docs/shitreed-task-tracker.html) ونزّله كملف HTML لتشغيله في المتصفح. عند تأكيد مهمة، يظهر وصف المهمة التالية تلقائياً. تقدّم المهام محفوظ محلياً في متصفح الجهاز.
- الجدول يساعد بالتنظيم فقط، وما يشغّل البرمجة أو الاختبارات تلقائياً.

## تم تنفيذه بالفعل
- تصميم عربي بنفسجي وبرتقالي، الصفحة الرئيسية، التصنيفات والبحث عن المتاجر بالمناطق.
- إنشاء مشروع Supabase مستقل باسم **shitreed** (Project ID: `ltwncrewggdrjevakwpb`).
- تثبيت جداول `customer_profiles`, `stores`, `products` مع سياسات **RLS**.
- اختبار مستشار الأمان في Supabase: بدون تحذيرات أمان وقت الفحص.
- حساب الزبون: إنشاء حساب / دخول / خروج عبر `supabase_flutter` بالبريد وكلمة المرور.
- جلب المتاجر المعتمدة والمنتجات النشطة من Supabase في النسخة المتصلة.
- GitHub Actions لبناء Android **debug APK** متصل بقاعدة شتريد عبر **Publishable Key** العلني، من غير أي مفتاح مسؤول سري.

## حالة البيانات والطلبات
- قاعدة شتريد جديدة، **لا تحتوي على أصحاب متاجر حقيقيين أو منتجات منشورة بعد**.
- عند اتصال التطبيق بالقاعدة يظهر تنبيه لطيف إذا ماكو متاجر/منتجات منشورة، ولا تُعرض المحلات التجريبية على أنها متاجر حقيقية.
- السلة الحالية تجريبية فقط، ولا توجد أوامر شراء أو دفع حقيقي.
- التسجيل بالبريد يعتمد على إعدادات Supabase Auth وتأكيد البريد، ويحتاج اختبار من هاتف المستخدم.
- خرائط Google، GPS، التوصيل، المدفوعات، تطبيق البائع والمندوب، ولوحة الإدارة **ليست منجزة بعد**.

## بناء نسخة متصلة
لا تستخدم مفتاح `service_role` أو `secret` داخل التطبيق مطلقاً. يستخدم مشروع شتريد **publishable key** فقط، وصلاحيات البيانات تحددها RLS.

```bash
flutter create --org com.shitreed --project-name shitreed_customer --platforms android .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug \
  --dart-define=SUPABASE_URL=https://ltwncrewggdrjevakwpb.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLIC_PUBLISHABLE_KEY
```

أحدث Workflow يتولى تهيئة Flutter وتمرير المفتاح العلني أثناء البناء. APK تجريبي وليس إصدار Google Play موقعاً للإنتاج.
