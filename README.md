# شتريد؟ موجود! 🛍️

**تطبيق الزبون — مشروع Flutter لأندرويد** لعرض المتاجر والمولات والخدمات في جميع مناطق بغداد.

## ما تم برمجته
- شاشة بداية عربية بنفسجي/برتقالي مثل التصميم المبدئي.
- واجهة الزبون الرئيسية مع البحث والتصنيفات والعروض.
- البحث باسم المتجر ونوعه ومناطق بغداد.
- صفحة تفاصيل المحل.
- سلة تفاعلية محلية للأغراض التجريبية.
- شريط تنقل: الرئيسية، البحث، السلة، الطلبات، حسابي.
- اختبار واجهة وأتمتة بناء APK تجريبي عبر GitHub Actions.

> **مهم:** البيانات والمتاجر والأسعار تجريبية. هذا ليس تطبيق تسوق فعلياً بعد.
> لا يعمل حالياً GPS أو ملاحة أو تسجيل حساب أو Supabase أو Google Places أو الطلبات والدفع.

## إنشاء APK من GitHub
1. افتح **Actions**.
2. اختر **Shitreed Customer APK**.
3. بعد نجاح Workflow افتح قسم **Artifacts** وحمّل **Shitreed-Customer-APK**.
4. يحتوي الأرشيف على ملف Android debug APK للتجربة فقط.

## التشغيل محلياً
```bash
flutter create --org com.shitreed --project-name shitreed_customer --platforms android .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```
