# شتريد؟ موجود! — الأسواق والمحلات في بغداد 🛍️

تطبيق Flutter للأندرويد باللغة العربية وبالتصميم البنفسجي والبرتقالي المعتمد.

## المزايا المبرمجة في الإصدار التجريبي v0.5.0
- تسجيل الدخول وإنشاء الحساب الحقيقي عبر Supabase Auth.
- محلات معتمدة ومنتجات منشورة وأسعار بالدينار العراقي، مع تصنيف وبحث.
- خريطة بغداد من Google Maps SDK، تحديد الموقع بإذن المستخدم، واتجاهات المتجر عبر خرائط Google الخارجية.
- مركز التاجر داخل التطبيق: طلب إضافة متجر، صور المنتجات، الأسعار والمخزون، إدارة الطلبات.
- سلة حقيقية لمتجر واحد ودفع عند الاستلام، حساب السعر والمخزون على خادم Supabase بواسطة دوال معاملات آمنة.
- متابعة الطلبات للزبون، إلغاء الطلب المسموح، وقبول ورفض الطلب لدى صاحب المتجر.
- صور عامة عبر Supabase Storage لا يرفعها إلا صاحب المتجر المصرّح به.
- قواعد RLS وفصل قراءة الطلبات/المتاجر وصلاحيات المستخدمين.

## الحالة الفعلية
التطبيق **ليس جاهزاً بعد للنشر التجاري النهائي**. كود الوظائف الجديدة ما زال يحتاج اختباراً متكاملاً على هاتف فعلي بحساب زبون وبائع مستقلين. قاعدة البيانات متصلة وتحتوي على حساب زبون، لكنها لم تحتوِ على متاجر ومنتجات حقيقية معتمدة عند آخر فحص.

**غير مكتمل:** تطبيق مندوب التوصيل، التتبع المباشر، لوحة إدارة مستقلة، الدفع الإلكتروني، الإشعارات الإنتاجية، حذف الحساب تلقائياً، إجراءات الدعم والنزاعات، وتوقيع Release/AAB مستقر.

## بناء Debug للتجربة
ينشئ workflow منصة Android ثم يمرر قيم Supabase العلنية ومفتاح Google Maps من GitHub Secrets. لا تُستخدم مفاتيح service_role أو مفاتيح Stripe في التطبيق. مفتاح Google Maps يجب تقييده بحزمة التطبيق وبصمة SHA-1 لشهادة التوقيع قبل الاستخدام الإنتاجي.

قبل النشر التجاري يلزم اختبار المعاملات والأمن، إعداد الدعم وسياسة الخصوصية، ضمان موافقة مالكي المتاجر، حفظ توقيع Release ثابت وبناء AAB واتباع متطلبات Google Play.
