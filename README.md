# شتريد؟ موجود!

مشروع تطبيق الزبون للبحث عن المتاجر والمولات والخدمات في جميع مناطق بغداد.

## خطة النسخة الأولى
- تسجيل ودخول الزبون
- البحث عن المتاجر والمنتجات حسب المنطقة
- عرض تفاصيل المتاجر والمولات
- السلة والطلبات وخيارات الاستلام والتوصيل

التقنية المستهدفة: Flutter وSupabase. هذه بداية المستودع، وليست نسخة APK جاهزة.
