# حماية رقم هاتف المتجر — جاهزية الترحيل

هذا التعديل ليس منشوراً بعد على Supabase Production.
RLS وحده يحدد الصفوف وليس أعمدة الهاتف. ترحيل الهاتف يعيد منح SELECT على أعمدة المتجر العامة فقط دون phone.
أضيف RPC shitreed_my_store_contacts: يقرأ المالك أرقام متاجره فقط بناء على auth.uid.
كود التاجر تحول لاستدعاء هذا RPC ولا يعرض رقم هاتف آخر عند عدم التفعيل.
تحديث API الموقع العام يمنع تضمين phone في JSON الكتالوج.
توجد أجزاء أخرى في شتريد ولوحة الإدارة تستخدم بيانات المتجر؛ تأكد من مراجعة جميع العملاء المتصلين قبل التفعيل في الإنتاج لتجنب كسر الاستعلامات.
يلزم اختبارات مقارنة للزائر والزبون والمالك والإدارة على بيئة معزولة، ونسخة احتياطية قابلة للاسترجاع.
لا تفعل هذا الترحيل مباشرة دون تحقق كامل؛ يجب إصلاح التسريب في Data API لا مجرد إخفاء الرقم من الواجهة.
