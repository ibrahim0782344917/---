# تفاعلات متجر السيد إبراهيم العاني
إعجاب، حفظ، تقييم 1–5، تعليقات بمراجعة مسبقة، بلاغات، سجل قرارات المشرف، وأدوار كاتب ومحرر ومشرف. يمنع RLS الوصول غير المصرح به. منشورات الكاتب مسودات فقط؛ المحرر والمالك أو الإدارة ينشرون.
تفعيل قاعدة الإنتاج لا يسبق نجاح الاختبارات والحماية. لا يحتوي هذا الترحيل على تحديثات للطلبات القديمة أو الدفع أو المنتجات.
لا تعتمد صور أفراد أو متاجر من الإنترنت ما لم تثبت الجهة والحقوق؛ المنتجات تستخدم صور مالك المتجر الحالية في Supabase.
