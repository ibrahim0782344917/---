# متجر السيد إبراهيم العاني — فيديوهات استوديو الهاتف والريلز

- Flutter: في إدارة المحتوى يختار **مالك المتجر** فيديو MP4 من استوديو الهاتف، حد ٤٠ ميغابايت، ويرفعه مع حفظ المسودة أو النشر. رابط الفيديو يُحفظ في public.alani_publications بعد نجاح الرفع؛ عند تعثر حفظ المحتوى تُجرّب إزالة الملف الجديد.
- قسم «فيديوهاتي» أصبح ريلز عمودية: فيديو واحد يعمل، السحب للأعلى/الأسفل، تشغيل وإيقاف، تكرار، شريط تقدم، تحديث، وصف وعنوان. إيقاف تشغيل الفيديو السابق عند الانتقال أو خروج التطبيق.
- المصدر الحقيقي: جدول alani_publications الموجود حالياً + bucket تخزين جديد alani-reels (مطلوب تفعيله). لا محتوى مختلق ولا تحميل فيديوهات من مواقع خارجية.
- تفرض سياسة storage.objects RLS: رفع/حذف صاحب المتجر المعتمد فقط، مسار store_id/user_id/random.mp4، منع جميع غير المصرح لهم من الرفع. حجم الملف 40 MiB وصيغة MP4 فقط.
- **خصوصية الفيديو:** bucket عام لعرض فيديوهات تسويقية للزبائن. مسودة المحتوى لا تظهر في قائمة الزبائن، لكن ملف الفيديو نفسه ليس سرياً إذا تسرب رابطه. يجب عدم رفع معلومات أو فيديوهات خاصة.
- لا بيانات زبائن ولا أوامر مدفوعات ولا بيانات طلبات تُمس في هذا التعديل. لا خدمة مدفوعة مفروضة.
- يلزم الاختبار على هاتف Android فعلي لاتصال الـ DNS، ودعم MP4، وحجم الملف، وسلوك السحب.
- هذا فرع تطوير، ليس ترخيصاً تلقائياً لدمجه في main. تفعيل مخزن الإنتاج يجب أن يأتي بعد اختبار ترحيل SQL والتأكيد على السعة والنسخ الاحتياطية.
- تشغيل الاختبارات والبناء عبر GitHub Actions من طلب المراجعة.
