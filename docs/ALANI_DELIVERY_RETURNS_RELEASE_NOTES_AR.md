# إتمام الطلب والاسترجاع — متجر العاني

ملف تهيئة فقط: docs/ALANI_DELIVERY_RETURNS_SAFE_STAGE_20261122.sql.
لا يطبق على قاعدة الإنتاج قبل نسخة احتياطية كاملة واختبار استرجاعها.
الزبون الذي يملك الطلب يؤكد الاستلام بعد حالة ready، وعندها تصبح الحالة delivered ويسجل الحدث في سجل الطلبات.
تقديم طلب إرجاع للزبون بعد delivered فقط؛ يذهب إلى مراجعة المالك مع سبب ووصف.
التاجر يراجع بترتيب submitted -> reviewing -> approved -> resolved، أو declining عند وجود مبرر.
لا توجد تسوية مالية أو رد أموال تلقائي؛ approved تعني قبول مراجعة الطلب فقط.
إلغاء الطلب قبل قبول المتجر يعمل مسبقا في change_cash_order_status ويرجع المخزون.
تصنيف delivery_issue يتيح تقديم بلاغ عن مشكلة التوصيل. لا يوجد إثبات مندوب مستقل.
المهاجر يحتاج اختبار صلاحيات الزبون والتاجر والزائر على قاعدة معزولة قبل تطبيقه.
