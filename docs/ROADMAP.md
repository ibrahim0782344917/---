# شتريد؟ موجود! — خطة تنفيذ تطبيق الزبون

## مكتمل في ملفات النسخة الأولية
- شاشة افتتاحية بنفسجي وبرتقالي، مع واجهة عربية RTL.
- الصفحة الرئيسية بأقسام المتاجر والمولات والعروض والخدمات.
- بحث تجريبي باسم المتجر أو المنطقة، وتفاصيل متجر وسلة محلية تجريبية.
- خيار منطقة "كل بغداد" ومناطق مختارة (لا يعني تغطية بيانات حقيقية).

## لم يُنفّذ بعد
- التسجيل الحقيقي، مصادقة المستخدمين، حذف الحساب.
- Supabase وسياسات RLS والمزامنة السحابية.
- متاجر وبيانات Google Places الحقيقية، المنتجات والأسعار والصور.
- موقع GPS والملاحة والتوجيه المستقل مثل Waze.
- طلبات حقيقية، دفع، مندوب، تتبع توصيل، وتقييمات.
- تطبيق صاحب المتجر وتطبيق المندوب ولوحة الإدارة.

## ضوابط التكامل
Google Places يوفر معلومات حسب توفرها وسياسات API، ولا يجوز افتراض توفر أسعار المنتجات. يتطلب مفتاح API مقيّداً، وتفعيل الفوترة، والالتزام بشروط الإسناد والتخزين. تحديث موقع الزبون يكون بإذن واضح؛ التتبع بالخلفية يتطلب مبرراً وامتثالاً لسياسات Google Play. بيانات المنتجات والأسعار يضيفها صاحب المتجر بعد التحقق.

## البناء
GitHub Actions ينشئ ملفات Android الأصلية عن طريق flutter create، ويحلل ويفحص ويبني APK debug تجريبياً.
ملف AAB الإنتاجي يتطلب توقيعاً وإعدادات وحماية إضافية.
