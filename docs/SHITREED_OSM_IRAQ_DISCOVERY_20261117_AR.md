# شتريد — بديل Google Places في العراق: OpenStreetMap

## القرار التقني
- **مصدر اكتشاف المحلات:** OpenStreetMap عبر Overpass، مع حدود صارمة ومؤقتة للاستخدام في التطوير.
- **قاعدة المتاجر المسجلة:** Supabase / `stores` (حالة `approved` فقط). لا يتحول عنصر OSM تلقائياً إلى متجر يبيع منتجات.
- **صفحة الخرائط:** `lib/maps/osm_discovery_page.dart`، تدعم تحريك الخريطة وتكبيرها والنقر على المؤشرات.
- **خادم الاستعلامات:** Supabase Edge Function `nearby-osm`، منشورة دون Google Cloud API key.
- **الرجوع إلى Google:** ملفات تكامل Google السابقة ما زالت بالمستودع لكنها ليست الشاشة الأساسية.
- **الدفع والفوترة:** لم نفعّل Google Billing أو أي خدمة مدفوعة جديدة.

## ضوابط الوضع التجريبي
1. طلب Overpass يكون **فقط عند ضغط المستخدم على «اكتشف المحلات»**، لا عند كل حركة للخريطة أو تحديث تلقائي.
2. حد الخادم: **5 طلبات/دقيقة للشبكة، 80 طلباً/اليوم للمنظومة كلها**، قبل الوصول إلى Overpass؛ قد تظهر رسالة «حاول لاحقاً» عند بلوغ السقف.
3. استعلام دائري بمدى 1.6 كم حول النقطة التي يختارها المستخدم، وبحد أقصى 50 نتيجة مع اسم وموقع حقيقيين في بيانات المصدر.
4. لا يتم تخزين النتائج المكتشفة في جداول المتاجر أو إعطاؤها شارة توثيق أو منتجات افتراضية.
5. المصدر المعروض: **© OpenStreetMap contributors** مع رابط الترخيص؛ احترم ODbL عند استخدام هذه البيانات أو دمجها لاحقاً.
6. في **APK المعاينة فقط** يستخدم `SHITREED_OSM_DEMO_TILES=true` لعرض بلاطات OSM العامة بحجم طلبات صغير. للتشغيل التجاري يجب اختيار **مزود بلاطات موثوق مع ترخيص مناسب، أو استضافة مستقلة** وضبط `SHITREED_TILE_URL` بعنوان HTTPS. لا تعتمد على الخوادم العامة عند التوسع.
7. خصوصية الموقع: لا يُطلب إذن المستخدم إلا بالضغط على «قريب مني». ويمكنه البحث بتحريك الخريطة بدون مشاركة موقعه.
8. رابط «هذا محلي» **مرحلة تعريفية حالياً**: يوجّه صاحب المحل لفكرة التسجيل في شتريد تاجر. نموذج المطالبة الفعلي والتحقق والاعتماد الإداري ما زال يحتاج مرحلة مستقلة.
9. تغطية بغداد وسائر العراق تعتمد على اكتمال بيانات OSM، وقد توجد محلات غير مسجلة. يستكملها نظام تسجيل التجار والتحقق من الملكية والمعلومات التي يقدمها أصحاب المحلات.
10. قبل إطلاق عام: **مزود بيانات/Overpass مستقل أو ملف بيانات محدث حسب الترخيص + تخزين كاش قانوني + مراقبة الاستخدام والتعافي**. الخوادم العامة ليست ضمان توافر تجاري.
