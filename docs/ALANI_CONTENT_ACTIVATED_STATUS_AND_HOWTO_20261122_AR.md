# تفعيل فيديوهات ومدونات ووصفات العاني — 22 نوفمبر 2026

## نتيجة تفعيل قاعدة البيانات
- طبقت migration باسم alani_publications_rls_enabled_20261122 في Supabase شتريد.
- تمت إضافة جدول public.alani_publications جديد، دون تغيير جداول الزبائن والمنتجات والطلبات.
- 4 سياسات RLS: الزبائن يرون المنشور فقط، والمالك وحده يستطيع الإضافة والتعديل والحذف.
- جميع اختبارات RLS على PostgreSQL معزول نجحت، واختباران مؤقتان على القاعدة الحية تم إلغاء معاملتيهما دون حفظ محتوى.
- العدد الحالي: صفر منشورات حقيقية. يحتاج المالك إلى كتابة أول محتوى.
- لم نؤكد بعد وجود نسخة احتياطية كاملة قابلة للاسترجاع. الترحيل إنشاء جدول جديد فقط.

## كيف تضيف محتوى من هاتفك
1. افتح تطبيق الزبون وسجّل الدخول بحساب مالك متجر السيد إبراهيم العاني.
2. افتح صفحة المتجر واضغط أيقونة القلم: إدارة الفيديوهات والمدونة.
3. اضغط منشور جديد واختر فيديو أو وصفة أو مدونة / مقال أو منشور.
4. اكتب العنوان والنص. للوصفة، املأ المكونات والتحذيرات. للفيديو، أضف رابط HTTPS.
5. حفظ مسودة يحفظ المحتوى للمالك فقط؛ نشر المحتوى يجعله ظاهراً للزبائن.
6. افتح تبويب الفيديو أو وصفاتي، أو اسحب القائمة للأسفل لتحديث المنشورات.

## من تطبيق Admin
افتح إدارة السيد إبراهيم العاني ثم المحتوى، واضغط إضافة، واختر نوع المحتوى. تحتاج أن تكون مالك المتجر على الخادم، وليس مجرد مستخدم بصلاحيات عامة.

## الفيديوهات
- روابط MP4 أو M3U8 المباشرة عبر HTTPS تشغّل داخل التطبيق.
- روابط صفحات YouTube ومواقع التواصل قد تفتح في متصفح/تطبيق خارجي.
- هذا الإصدار لا يرفع الفيديوهات من الهاتف إلى Storage ولا ينسخ فيديوهات TikTok وFacebook وYouTube على الخادم.
- نسخ المحتوى الخارجي يحتاج إذن الحقوق وسياسات تخزين وإشراف قبل تنفيذه.

## حدود التفعيل
- لا توجد تعليقات أو إعجابات أو جدولة نشر أو رفع ملفات فيديو كبير حالياً.
- وصف المنتجات والأعشاب للتثقيف فقط، وليس تشخيصاً أو ادعاء علاجياً.
- لم يُفعّل الدفع أو التوصيل أو الاسترجاع بفعل هذا الترحيل.
