## 4. رحلة الشراء والاسترجاع
- اختبارات الشراء المعزولة نجحت على قاعدة TEST ونظام تأكيد المجموع مع 5000 دينار توصيل.
- اختبار SQL فعلي على TEST نفّذ بشكل مؤقت:
  `ready → delivered → submitted → reviewing → approved → resolved`.
- الاختبار كان ضمن `BEGIN/ROLLBACK`. بعده: **صفر طلبات استرجاع تجريبية مخزنة**،
  ولم تتغير حالتا الطلبين `ready` الأصليين.
- ما زال يلزم اختبار مندوب/إثبات تسليم ميداني/تعويض مالي حقيقي على بيئة قبول معزولة قبل البيع التجاري.
