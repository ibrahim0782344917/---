# الإدارة الموحدة — شتريد والسيد إبراهيم العاني

## قرار التصميم

**تطبيق Admin واحد فقط:** `admin_app` (اسم حزمة Android التجريبية: `com.shitreed.shitreed_admin`).

لم يعد هناك مشروع بناء مستقل باسم `alani_admin_app` في فرع التوحيد. نُقل كود وحدات متجر السيد إبراهيم العاني إلى `admin_app/lib/alani_store_admin_page.dart` مع وحدتي `alani_store_api.dart` و`alani_dashboard_filters.dart`.

حُفظت النسخة السابقة الكاملة، دون تغيير بيانات، في `backup/alani-duplicate-admin-before-consolidation-20261118`.

## ما يجده المدير في نفس التطبيق

- إدارة شتريد العامة: المتاجر، المنتجات، الطلبات، الزبائن، الموظفون، سجلات الإدارة، الرتب والمستويات (بحسب الدور).
- قسم «السيد إبراهيم العاني»: المنتجات والمخزون، الطلبات وحالاتها، الفيديوهات والوصفات والمدونة، مراجعة الاسترجاع والتعويض، مؤشرات المنتجات والطلبات.
- لا تظهر وحدة المتجر إلا لدور `super_admin` أو `operations`. **هذا شرط عرض فقط، وليس تفويضاً نهائياً**: الخادم يعيد التحقق من مالك متجر العاني قبل أي قراءة/تغيير. قد يحتاج المدير العام غير المالك ربط صلاحية موثوقاً قبل استخدام الوحدة.
- لا يطلب قسم العاني كلمة مرور ثانية؛ يستخدم `Supabase Auth` من التطبيق الأساسي. لا توجد أسرار `service_role` في APK.
- جدول محتوى العاني والاسترجاع لم يُفعلا بعد؛ لا يتم الادعاء بتشغيل نشر المحتوى أو المعالجة المالية.

## APK والتثبيت

- تشغيل `Shitreed Three-App Release Readiness` على فرع `feature/alani-unified-admin-20261118`، والبحث عن `Unified-Shitreed-AlAni-Admin-PREVIEW-NOT-FOR-PRODUCTION`.
- الـ APK تجريبي وغير موقّع للنشر على Google Play. يلزم اعتماد مفتاح توقيع ثابت قبل إصدار نهائي لتحديث التطبيق دون إعادة تثبيت.
- لم يتم حذف أي تطبيق من جهاز المستخدم آلياً. إذا كانت النسخة السابقة `alani_admin_app` مثبتة، يزيلها المستخدم من **الإعدادات ← التطبيقات ← alani_admin_app ← إلغاء التثبيت**. بيانات Supabase السحابية لا تُحذف بإزالة APK.
- شتريد Admin القديم قد يحمل توقيع Debug مختلفاً عن البناء الجديد؛ عند رفض تثبيت APK فوق القديم، احفظ أي بيانات محلية مهمة وأزل التطبيق القديم ثم ثبّت النسخة الموحدة. لا تُحذف بيانات الخادم.

## حدود التسليم

- التغييرات في فرع التطوير فقط، ضمن Pull Request مراجعة مسودة `#10`.
- لا دمج إلى `main` ولا نشر على Google Play ولا تعديل بيانات إنتاج.
- يلزم نجاح `flutter analyze` و`flutter test` و`flutter build apk`، ثم اختبار تسجيل دخول المدير والمالك، وفتح وحدة العاني ومراجعة RLS والصلاحيات على جهاز حقيقي قبل إعلان الإنجاز النهائي.
- واجهة إدارة الويب `/admin` تبقى قناة الويب؛ الطلب هو توحيد **تطبيق Android Admin** لا إزالة موقع الإدارة.
