# جاهزية الإصدار التجاري — شتريد؟ موجود!

**الحالة:** تطوير نشط؛ لا يُنشر على الإنتاج أو Google Play قبل الاختبارات والاعتمادات أدناه.

## ما أصبح موجوداً في كود التطبيق
- Flutter بالعربية وتصميم بنفسجي/برتقالي، الصفحة الرئيسية والتصنيفات والبحث وخريطة بغداد.
- تسجيل حقيقي عبر Supabase Auth بالبريد وكلمة المرور.
- عرض متاجر **approved** فقط ومنتجاتها النشطة وأسعارها ومخزونها وصورها.
- لوحة صاحب المتجر داخل تطبيق Android: إرسال طلب تسجيل متجر، إدخال موقعه، إضافة منتجات وصورها ومخزونها.
- صور المتاجر في Supabase Storage مع حد 5 MB وقيود رفع لصاحب المتجر.
- سلة لمتجر واحد، وطلب COD يتحقق من الأسعار والمخزون داخل معاملة PostgreSQL.
- للزبون تاريخ طلبات وإلغاء الطلب الموضوع بحالة placed فقط.
- للتاجر قبول ورفض الطلب وتحويله إلى التحضير ثم الجاهز للتسليم.
- خرائط Google SDK: تتطلب تفعيل مفتاح Android المقيّد بشكل صحيح، والاختبار على الهاتف.
- قاعدة مستقلة باسم shitreed وRLS.

## أعمال واجبة قبل نشر التطبيق للعملاء
- [ ] تجربة تسجيل زبون حقيقي وتأكيد بريده عبر هاتف Android.
- [ ] تسجيل تاجر حقيقي والتحقق من ملكيته واعتماد متجره إدارياً. لم يُنجز تطبيق إدارة مستقل بعد؛ الاعتماد حالياً من Supabase Dashboard.
- [ ] تجربة رفع صورة حقيقية ومراجعة صلاحيات Storage وصور المنتج وإدارة المخزون.
- [ ] اختبار دورة طلب كاملة بحسابين مستقلين، السعر والتزامن وحجز المخزون وإلغاء الطلب والرفض؛ لا توجد عمليات طلبات حقيقية حتى الآن.
- [ ] إضافة وصف الطلب، رسوم التوصيل وسياسة التسعير النهائية، والتأكد من أن سعر الشحن لا يُحسب اعتماداً على الهاتف.
- [ ] بناء تطبيق المندوب، تعيين الطلبات والتتبع والتسليم الفعلي والتحقق من التسليم.
- [ ] بناء لوحة إدارة احترافية ومراجعة البلاغات والتجار والنزاعات.
- [ ] إضافة نظام إشعارات موثوق عبر FCM حسب تفضيلات المستخدم.
- [ ] ربط بوابة دفع معتمدة بالعراق بعد الموافقة على الرسوم والتسوية وتفويض الدفع. الموجود الآن COD فقط.
- [ ] مراجعة أمن دوال SECURITY DEFINER التي تتحكم بالطلبات، واختبارات وصول بين حسابات مختلفة. المستشار الأمني يصدر تحذيراً يتطلب مراجعة قبل الإنتاج.
- [ ] تفعيل Supabase Auth **Leaked Password Protection** من اللوحة إذا كان متاحاً للخطة.
- [ ] إضافة حذف الحساب وإجراءات خصوصية واسترجاع البيانات وحالات الطوارئ. خصوصية أولية في PRIVACY_POLICY_DRAFT_AR.md.
- [ ] إعداد توقيع Android RELEASE ثابت واستعماله مع Google Maps API key وحفظ نسخة احتياطية آمنة من المفتاح.
- [ ] إصدار AAB موقع ومستقر، اختبارات الأجهزة والتكامل والأداء، ثم متطلبات Google Play والإفصاحات والمراجعة.
